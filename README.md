# PADA-3DACB

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![DOI](https://zenodo.org/badge/1349792687.svg)](https://zenodo.org/badge/latestdoi/1349792687)

Package scaffold for the PADA-3DACB research codebase.

Phase 2 provides configuration, path, reproducibility and logging utilities.
Scientific implementation modules are added in later phases.

## Citation

If you use this software in academic work, please cite the archived Zenodo release associated with the DOI badge above. The repository also includes a [`CITATION.cff`](CITATION.cff) file so that GitHub and compatible scholarly tools can generate citation metadata automatically.

The Zenodo DOI badge becomes active after the repository is enabled in the Zenodo GitHub integration and the first GitHub release is archived. The badge is linked by the GitHub repository identifier, so it will continue to resolve to the latest Zenodo DOI without requiring the README to be edited for every new release.
